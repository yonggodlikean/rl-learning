01 / RETURN

Gt = rt+1 + γGt+1

从后往前算。第一个奖励不打折，后续奖励每晚一步乘一次 γ。

02 / VALUE

V(s) = E[Gt | St = s]

一次轨迹的回报是样本；状态价值是所有可能轨迹回报的期望。

03 / BELLMAN

V = R + γPV

P 的每一行对应一个当前状态，元素是去往各后继状态的概率。
