# 实战案例 1：用户留存运营的动态规划（策略迭代与值迭代）

对应教材章节：**《EasyRL（蘑菇书）》§2.3 马尔可夫决策过程（MDP）与动态规划控制**

---

## 业务背景与问题定义

在电商或内容平台的用户增长业务中，用户在平台经历生命周期的状态变迁：
* **状态 0（候选/沉睡用户）**：有流失风险，对普通运营脱敏，但给券有很大概率转化为留存；
* **状态 1（留存用户）**：忠诚度高，自然留存率达 90%。如果再给大额补贴，反而造成营销浪费（过度补贴）。

运营部门有两类动作：
* **动作 0（普通运营）**：零补贴，仅系统常规触达；
* **动作 1（强力激励）**：发放高面额权益补贴券。

**核心目标**：在已知转移矩阵 $P(s'|s,a)$ 与奖励矩阵 $R(s,a)$ 的条件下，使用强化学习经典的**策略迭代**与**值迭代**算法，求出用户在不同状态下的**终身价值最优决策策略**。

## 你的任务

请打开 `core_solver.py`，根据函数签名和文档注释中的数学公式，亲手补齐以下三个方法：
1. `policy_evaluation(policy, theta=1e-6)`：策略评估循环；
2. `policy_iteration()`：策略迭代完整闭环；
3. `value_iteration(theta=1e-6)`：值迭代完整闭环。

完成后，在终端运行：
```bash
python classic_rl/scenarios/user_retention_dp/run.py
```
